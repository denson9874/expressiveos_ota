ExpressiveOS 1.3.1 for the Pixel 11 — Winter Camellia
==============================

ExpressiveOS 1.3.1 is an in-place polish update for 1.3 with RCS messaging fixes, Expressive Launcher 5.1.9, updated Wild Kernels r23 root out of the box, and reliability fixes across OTA updates, audio and contacts.
On 1.3 (or an earlier 1.x release), open Settings → System → System updates and install 1.3.1 — your apps and data stay right where they are.

───────────────────────

✨ What's New & Improved
==============================

1. 💬 RCS messaging & Expressive Studio polish
- RCS setup & carrier services: fixed background registration issues in Google Messages and carrier IMS services so RCS chats connect reliably after setup or an update.
- Expressive Studio: importing an XML configuration file now opens straight to your Downloads folder and accepts both plain XML and Base64-encoded files, and Google Photos legacy device compatibility now defaults to off on fresh installs so native Pixel camera and backup features stay active out of the box.

2. 🚀 Expressive Launcher 5.1.9
- Ahead-of-time compiled: Expressive Launcher is now compiled into native code during the build, making cold starts, app-drawer scrolling and Recents gesture transitions noticeably snappier right after boot.
- Lower memory & idle drain: reduced background graphics memory and idle wakeups on Adaptive refresh-rate screens.
- Pixel Launcher mode switch: fixed a boot-time property check so switching between Expressive Launcher and Pixel Launcher in Expressive Studio applies cleanly across reboots.

3. 🔓 Updated Wild Kernels r23
- Updated to Wild Kernels r23 (6.12.92 with BakaSU and susfs built in). Nothing gets root until you allow it in the BakaSU app.
- Install the BakaSU manager APK from Nightly (https://github.com/Baka-SU/BakaSU/actions) or Release (https://github.com/Baka-SU/BakaSU/releases), or flash the matching boot-stock.img if you prefer an unrooted boot image.

4. 🔧 Audio, OTA, Recovery & Contacts fixes
- ViPER4Android: mounts the audio effect overlay earlier during boot (post-fs) so the Pixel audio HAL always detects ViPER4Android on its very first start.
- Recovery & factory reset: fixed SELinux rules in recovery and fastbootd so factory data resets complete cleanly on Pixel 11 hardware.
- Post-OTA boot stability: fixed two Virtual A/B snapshot merge bugs (snapuserd unaligned sector buffer sizing and pkill -SIGNAL argument parsing) that could interrupt background partition merges after an OTA reboot.
- Custom contact ringtones: assigning a custom ringtone to an individual contact in Google Contacts works again without crashing.
- Face Unlock enrollment: rotating or folding the screen during Face Unlock setup no longer opens a duplicate enrollment screen.

💬 Community Notes
==============================

- Who it's for: the Pixel 11 (cubs) only. Install the build made for your exact phone.
- Updating from 1.3: open the Updater and install 1.3.1; phones on the November 15 1.3 release receive a compact incremental update, and your apps and data stay intact.
- Looking ahead to ExpressiveOS 2.0 (December): 1.3.1 installs in place on the 1.x channel. Next month's ExpressiveOS 2.0 moves onto a clean pure-AOSP Android 17 foundation with its own 2.0 update channel — 1.3.1 will never auto-update to 2.0 unexpectedly, and upgrading from 1.3.1 to 2.0 will require a one-time clean install (back up your data first; all 2.x updates after 2.0 will install in place as usual).
- Clean installs: flash Google's November 2026 factory image (CP4A.261105.040) first, then install ExpressiveOS 1.3.1 with the web installer or fastboot.
- Found a bug? Post it in the Bugs topic of the Expressive Group on Telegram.
