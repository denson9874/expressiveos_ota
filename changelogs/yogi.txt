ExpressiveOS 1.3 for the Pixel 11 Pro Fold — Winter Camellia
==============================

ExpressiveOS 1.3 comes with root built in, an Adaptive minimum refresh rate, working lock screen widgets, and fixes for Magic Cue, battery health and Limit to 80%. Nothing gets root until you allow it.
On 1.2, open the Updater and install it, and your apps and data stay. Coming from stock Android or another ROM, installing it wipes the phone, so back up first.

───────────────────────

✨ What's New & Improved
==============================

1. 🔓 Root, out of the box
- Before: getting root meant patching the boot image yourself and adding a separate module to hide it.
- Now: root is built into ExpressiveOS's kernel (Wild Kernels' kernel with BakaSU and susfs), so no extra module is needed to hide it. Nothing gets root until you allow it in the BakaSU app.
- The BakaSU app doesn't come with the ROM. Install the Nightly build: https://github.com/Baka-SU/BakaSU/actions. Open the latest successful run and download its APK. You need a GitHub account to download it.
- Don't use BakaSU's Release build (v4.2.0-rc3) for now: it's older than the root built into 1.3, so it shows "Manager update required". Root still works, but the Nightly clears it. "Direct install" isn't needed: root is already in 1.3's kernel.
- Don't want root? Download the file ending in boot-stock.img from the same downloads page as your build, and flash it to the boot partition: fastboot flash boot <that file>.
- Installing with the web installer? Pick BakaSU or Stock before you install, and it puts the right boot image on both slots.

2. 🌀 An Adaptive minimum refresh rate
- Before: the screen never went below 60 Hz unless you changed it, and Settings showed "Minimum refresh rate: 60 Hz" even on screens that go lower.
- Now: the minimum is Adaptive, so the screen drops as low as it can when nothing moves, which saves battery. Settings > Display > Screen refresh rate shows "Adaptive, up to 120 Hz". You can still pick a fixed minimum there.

3. 🧩 Lock screen widgets work with Expressive Launcher
- Before: tapping "Add widget" on the lock screen widget hub did nothing when Expressive Launcher was your Home app.
- Now: it opens Expressive Launcher's widget picker. In Pixel Launcher mode, Pixel Launcher's picker opens as before.

4. 📱 Pixel 11 fixes
- Magic Cue: it closed every time it opened a screen. It works now.
- Battery health: Settings > Battery > Battery health now shows your battery's status and capacity.
- Limit to 80%: on 1.2 the switch stayed on, but the phone still charged to 100%. It now stops at 80%.
- NFC: the phone now loads its own NFC settings instead of falling back to generic ones.

5. 🔧 Smaller fixes
- Recovery shows which ExpressiveOS version is installed.

💬 Community Notes
==============================

- Who it's for: the Pixel 11 Pro Fold (yogi) only. Install the build made for your exact phone.
- Updating from 1.2 or older: open the Updater and install 1.3; your apps and data stay. If you patched the boot image for root yourself, you don't need to again after this update. Install the BakaSU app instead.
- Installing fresh: ExpressiveOS's fastboot packages don't carry the bootloader or modem. Flash Google's November 2026 factory image for your phone first (CP4A.261105.040, not a newer one or a beta), then ExpressiveOS, with the web installer or fastboot. On the Pixel 11 series, the installer and fastboot refuse a phone that has another bootloader.
- A new web installer: it has a new look, and while it installs it grows a flower in your phone's colours, from a seed to a full bloom.
- Found a bug? Post it in the Bugs topic of the Expressive Group on Telegram.
- Validation:
  - This build comes from the same sources as the Pixel 11 Pro XL build, which was installed as an update from 1.2 and checked on a phone before release.
