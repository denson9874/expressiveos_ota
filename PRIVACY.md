# Privacy policy: ExpressiveOS release backup

Last updated: November 13, 2026

This policy covers the Google sign-in client named "RClone" that the ExpressiveOS project uses to back up its own release files to Google Drive. It is run by Daryl Denson, the developer of ExpressiveOS.

## Who uses it

Only the developer. The client is not offered to ExpressiveOS users, is not part of the ROM, the Updater, the web installer or Expressive Launcher, and nobody else is asked to sign in to it.

## What it accesses

When the developer signs in with his own Google account, the client can read, add and remove files in that account's Google Drive. It uses that access for one purpose: to copy ExpressiveOS release files to a backup folder, list them, and remove old releases.

## What is collected, stored and shared

- No personal information is collected from anyone.
- No Google user data is sold, shared with third parties, used for advertising, or used to train AI models.
- The sign-in token is stored as a secret in the project's build tooling and is used only to run the backup. It can be revoked at any time at https://myaccount.google.com/permissions.

The client's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

## ExpressiveOS itself

This page is only about the backup client. The ROM's source code is public at https://github.com/ExpressiveOS.
